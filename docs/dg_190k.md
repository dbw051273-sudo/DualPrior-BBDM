# FOMLDG and SWAD on the 190k BBDM protocol

The two configurations use the same Swin-UNet and 9,000 paired liver, kidney,
and brain training patches as Base. Four-step blocks alternate PI-to-H&E
translation with H&E self-reconstruction before step 90,000. From step 90,000,
all updates train PI-to-H&E. Breast is held out from training and model
selection. Both runs use seed 1234, batch size 4, BF16 and one GPU.

- **FOMLDG** retains the temporary inner SGD update from MLDG (learning rate
  0.0001). The outer gradient sums the meta-train gradient and the held-source
  gradient at the temporary parameters with weight 1. The first-order
  approximation drops the Hessian term. The held source rotates by step.
  A batch contains two examples from that source and one from each other
  source. The self-reconstruction steps use the ordinary optimizer update.
  Generation uses the EMA weights at step 190,000.
- **SWAD LossValley** collects weights at each optimizer step after 90,000.
  It evaluates residual L1 on all 1,336 source validation pairs every 1,000
  updates. The start window contains three segments. The end rule uses six
  segments and a tolerance of 0.30 above the start-window mean. Segment
  means are weighted by their update counts. If no start window is found,
  the final validated segment is used and the training log records the fallback.
  Generation uses the finalized average from the 190,000-update run.

## Commands

Run from the repository root in an environment with the training dependencies
and a BF16-capable CUDA device. Set `DATA` to your directory containing
`liver`, `Kidney`, and `Brain`, each with paired `train`, `val`, and `test`
subdirectories. Set `BREAST_PI` to the 5,636 input patches in the held-out
breast cohort. The source configuration retains the published PI inversion.

The reported evaluation used PyTorch 2.5.1 with CUDA 12.1, torchvision 0.20.1,
torchmetrics 1.9.0, torch-fidelity 0.4.0, and Cellpose 4.2.1.1. Install the
evaluator versions below in addition to the repository dependencies.

```bash
python -m pip install torchmetrics==1.9.0 torch-fidelity==0.4.0 cellpose==4.2.1.1 natsort==8.4.0 tensorboard
export CUDA_VISIBLE_DEVICES=0
DATA=/path/to/Datasets_processed
BREAST_PI=/path/to/held_out_breast/input

python tools/train_dg_190k.py --config configs/fomldg_first_order_190k.yaml --data-root "$DATA" --out runs/fomldg
python tools/gen_dg_breast.py runs/fomldg/run.yaml runs/fomldg/ws300-e3/FOMLDG-190K/checkpoint/last_model.pth 5636 8 fomldg190k "$BREAST_PI"

python tools/train_dg_190k.py --config configs/swad_lossvalley_190k.yaml --data-root "$DATA" --out runs/swad
python tools/gen_dg_breast.py runs/swad/run.yaml runs/swad/ws300-e3/SWAD-ORIG-190K/checkpoint/last_model.pth 5636 8 swad190k "$BREAST_PI"

python fast_official_eval.py official_eval/condition gens_screen/fomldg190k official_eval/ground_truth fomldg.json 50
python fast_official_eval.py official_eval/condition gens_screen/swad190k official_eval/ground_truth swad.json 50
```

Generation uses six time points and `eta=[1,1,0,0,0,0]`. Evaluation uses the same
5,636 aligned PI/H&E pairs, Cellpose nuclear-mask Dice and signed
generated-to-PI PCC as Base. The metrics come from single runs. The repository
contains summary metrics and code. Access to paired tissue data and weights is
described in the main README.

## Historical configurations

The older MLDG-inspired configuration applies source-loss reweighting at the
current parameters. The older SWAD-inspired configuration begins averaging
after a training-loss threshold and averages through the last update.

| Historical variant | PSNR (dB) | SSIM | LPIPS | FID | Dice | PCC |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Source-loss reweighting | 16.56 | 0.763 | 0.220 | 40.43 | 0.544 | 0.824 |
| Training-loss averaging | 15.71 | 0.741 | 0.244 | 44.39 | 0.528 | 0.794 |

Method references: [MLDG](https://arxiv.org/abs/1710.03463),
[SWAD](https://arxiv.org/abs/2102.08604).
